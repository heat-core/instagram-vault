# Security & Privacy Policy

## Our Privacy Commitment
**Instagram Vault & AI Studio** is designed from the ground up as a **100% Local-First** application.
- **Zero Cloud Storage of Personal Data**: Your photos, videos, captions, database, and session tokens reside exclusively on your local disk.
- **No Password Storing**: The app uses passwordless authentication (In-App official browser window or session ID cookie). Your plaintext Instagram password is never stored or transmitted.
- **Local SQLite Database**: All records and metadata are stored in your private local SQLite database.

## Reporting a Security Vulnerability
If you discover a potential security vulnerability within this project, please **do not** open a public issue.
Instead, report the issue privately to the maintainers via GitHub Security Advisories or by emailing the project maintainers.
