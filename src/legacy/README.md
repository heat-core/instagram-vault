# اسکریپت‌های اولیه و قدیمی (Legacy Prototype Scripts)

این دایرکتوری شامل اسکریپت‌های خط فرمان (CLI) اولیه پروژه است که در مراحل اولیه توسعه مورد استفاده قرار می‌گرفتند:

- `01_discovery.py`: کشف اولیه پست‌ها (اکنون توسط `src/services/discovery_service.py` بازنویسی و مدیریت می‌شود).
- `02_downloader.py`: دانلودکننده اولیه رسانه‌ها (اکنون توسط `src/services/download_service.py` جایگزین شده است).
- `03_ai_analysis.py`: پایپ‌لاین تحلیل هوش مصنوعی اولیه (اکنون توسط `src/services/ai_service.py` مدیریت می‌شود).
- `04_taxonomy_and_export.py`: دسته‌بندی و ایجاد کاتالوگ HTML اولیه (اکنون توسط `src/services/taxonomy_service.py` اجرا می‌شود).

> **توجه:**  
> تمام قابلیت‌های این اسکریپت‌ها به معماری ماژولار و امن شی‌ءگرا در پوشه `src/services/` منتقل شده و با سیستم کنترل جاب‌ها (`JobManager`) و دیتابیس هماهنگ است.  
> این اسکریپت‌ها صرفاً جهت حفظ تاریخچه و مراجعات احتمالی در این بخش نگهداری می‌شوند.
