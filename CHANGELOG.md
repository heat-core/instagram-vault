# Changelog

All notable changes to this project will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-03
### Added
- **Full-Stack Desktop Architecture**: High-performance Electron + React 19 + TypeScript + Vite frontend with FastAPI + SQLite backend.
- **Universal Multi-Mode Downloader**: Support for continuous downloading of Saved posts, Liked posts, Reels, IGTV, and High-Resolution Carousels.
- **In-App Official Instagram Authentication**: Passwordless official browser sign-in and manual F12 cookie login preventing account flags.
- **Direct Real-Time Discovery Sync**: Direct synchronization of saved and liked feeds with cursor-based pagination.
- **AI Multimodal Vision Pipeline**: Automatic categorizations, tags, and semantic summaries using Gemini Vision / OpenAI compatible APIs.
- **Audio & Speech Transcription**: Audio extraction and speech transcription for reels and videos.
- **Enterprise Media Inspector Drawer**: Video player controls with keyboard shortcuts (Space, M, F, ±5s arrows), variable speeds (0.75x–2.0x), and volume sliders.
- **Physical Folder & Desktop Drag-and-Drop**: Direct drag of media files from the application to the Windows desktop and custom folder export.
- **Duplicate Media Detection**: SHA-256 and perceptual deduplication for zero redundant disk storage.
- **100% Isolated Bilingual Support**: Full English and Persian interfaces with bidirectional lookup, RTL/LTR layout management, and localized numbers.
